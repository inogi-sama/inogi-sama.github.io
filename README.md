# Xu Zihan — Personal Academic Website

A responsive personal resume and research website built with plain HTML, CSS, and JavaScript.

## Structure

```text
resume-site/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
│   ├── CV.pdf       (optional)
│   ├── photo.jpg    (optional)
│   └── favicon.ico  (optional)
└── README.md
```

Open `index.html` directly in a browser. No build step or external dependency is required.

The `assets` directory is reserved for a downloadable CV, portrait, and favicon when those files are available.
